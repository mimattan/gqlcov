# @gqlcov/core

GraphQL schema coverage from captured operations: output fields, arguments, input-type fields, enum values and value classes.

```sh
npm install -D @gqlcov/core graphql
```

The coverage engine behind the `gqlcov` CLI: coverage computation, merge, diff, gate, and capture file I/O. Most projects use it indirectly through `@gqlcov/cli` and a capture package.

Part of [gqlcov](https://github.com/mimattan/gqlcov): GraphQL schema coverage measured from what your E2E tests actually executed. See the main README for the full guide.
